# 🌛  MoonFit

MoonFit es una aplicación de gestión de centros deportivos MoonFit es un proyecto personal desarrollado con el objetivo de crear una plataforma web para la gestión integral de un gimnasio. La aplicación estará orientada tanto a los propietarios y trabajadores del centro como a los propios usuarios, ofreciendo herramientas que faciliten la administración del gimnasio y mejoren la experiencia de sus clientes.

Desde el punto de vista de la administración, MoonFit permitirá gestionar usuarios, coordinar clases, controlar horarios, administrar monitores y realizar las tareas habituales de organización del centro. Por otro lado, los clientes podrán consultar sus rutinas de entrenamiento, inscribirse en clases, revisar sus reservas, acceder a información sobre el gimnasio y gestionar su perfil desde una única plataforma.
